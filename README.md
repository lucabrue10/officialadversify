# Adversify — Coming Soon

Cinematic, glossy "coming soon" placeholder for the Adversify brand launch. A single self-contained `index.html` (inline CSS + JS) — no build step, no dependencies beyond Google Fonts.

## Run locally

Just open `index.html` in a browser, or enable GitHub Pages on this repo to host it directly.

## Notes

- Respects `prefers-reduced-motion` (disables parallax and non-essential animation).
- Parallax is skipped on touch devices.
- All text content (headline, wordmark, tagline, copyright) lives directly in `index.html`.
